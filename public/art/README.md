# Preview artwork

Selected original PNGs from **Free Icon Pack v3.1 (Basic)** by **@gvesster**.
The original file for each image is recorded in `sources.json`; the supplied terms are in `LICENSE.txt`.

The preview uses the variants without heavy outlines. Supplied PNGs remain unmodified; the Battle mark composes two sword images with CSS, and lost hearts use a grayscale/faded presentation. Coin balances and reward icons use the pack's Golden Coin 2nd variant.

Matching original icons created with the built-in image generator live separately in `generated/`. Their prompts and provenance are in `generated/prompts.json`. These cover the missing pictograms and navigation controls; the supplied pack's license applies to its original files.

Only these selected assets are included. The full source archive and unrelated pack artwork are not part of the preview.
