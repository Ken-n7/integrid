# Generated companion icons

Created for the INTEGRID localhost preview with the built-in `image_gen` tool, using the supplied pack as a style reference. The original pack PNGs are kept separately and remain unmodified.

The set includes Hint, puzzle, map, back arrow, Undo, Restart, Download, controller, party popper, finish flag, thumbs up, portrait phone, printer and pie. Right/down chevrons reuse the back-arrow image with CSS transforms so their shapes match exactly.

All files are transparent PNGs copied from the selected generator outputs without changing their pixels or alpha. `prompts.json` records the final prompts, output filenames, dimensions and file sizes. Full generator outputs remain in their original generation folder as well.
